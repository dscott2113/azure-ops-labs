# Lab 00 – Azure Foundation

## Objective
Establish a clean Azure foundation that will be reused by all future labs, focusing on governance, cost control, and operational visibility.

## Scope
- Resource group structure for labs
- Standardized naming and tagging
- Cost management baseline
- Logging foundation

## Outcome
A repeatable Azure baseline that reflects real-world cloud administration best practices rather than one-off demo deployments.
