# Naming Standard (Simple)

Format:
<workload>-<type>-<env>-<region>-<nn>

Meaning:
workload = what this belongs to, in real world could be HR, finance etc.
type = what kind of azure resource it is
env = dev/test/prod etc
region = azure region
nn = number so things are unqiue if we have 2 of the same of the rest of the options

Examples:
- opslab-rg-lab-eus-01
- opslab-vnet-lab-eus-01
- opslab-law-lab-eus-01
