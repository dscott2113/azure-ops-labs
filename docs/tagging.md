# Tagging Standard

All Azure resources created in this repo should include these tags:

- owner: your name or handle (ex: dscott)
- env: lab
- lab: lab-00 / lab-01 / etc
- costCenter: personal
- expiresOn: YYYY-MM-DD (recommended)

Example:
owner=dscott
env=lab
lab=lab-00-foundation
costCenter=personal
expiresOn=2026-02-01
